## 2. 独立评估（pass@4 · 40 题 heldout · 与 v1 同题池）

### 2.1 三方对照

| 组 | 题级 pass@4 | 轨迹级通过率 | f2p 均值 |
|---|---|---|---|
| base（原始模型）| 15.0%（6/40）| 5.0%（8/160）| 0.0697 |
| v1-lora-50（历史）| 10.0%（4/40）| 5.0%（8/160）| — |
| **r2-lora-70（本次）** | **17.5%（7/40）** | **7.5%（12/160）** | **0.0936** |

### 2.2 逐题差异

- **共同通过（4 题）**：dvc-3493 / dvc-4623 / dvc-5148 / dvc-5732（dvc 系列为稳定能力）；
- **仅 r2-lora 通过（3 题）**：moto-6306、mypy-15297、mypy-15490；
- **仅 base 通过（2 题）**：moto-6374、mypy-15876；
- f2p 提升最大的题：dvc-4623（+4）、dvc-5732（+4）、mypy-15297（+4）、mypy-15490（+3）。

### 2.3 结论（含统计谨慎性）

1. **首次出现正向增益**：v1 损害能力（15%→10%），v2 反转为提升（15%→17.5%）；
2. **三个指标同向**（题级 +2.5pp / 轨迹级 +50% / f2p +34%）——方向一致，非单点波动；
3. **统计边界诚实说明**：40 题样本下 ±1 题 = ±2.5pp，题级提升处于噪声边缘——**"不再损害 + 轻微改善"是可靠结论，"显著跃升"尚不成立**；
4. **训练内 vs 泛化的落差**：训练内 reward 2.2×、val@1 0.5，但泛化仅小幅提升——提升主要来自"题池内适应"，泛化需更多数据多样性/步数/容量（见 §4）。
