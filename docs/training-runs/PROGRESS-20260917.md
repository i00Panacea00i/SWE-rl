## 五、GPU 内存问题完整分析（存档）

**现象**：多次 `torch.OutOfMemoryError`（44.39GiB 全卡）。

**排查结论**：
1. GPU 硬件无问题：nvidia-smi 空载 0MiB / 46068MiB，无外部进程、无 MIG
2. 根因 = **两个进程峰值叠加**：训练进程（全量 staging 29.11GB）+ vLLM（resume 后 14.95GB）= 44.06GB ≈ 全卡
3. 流程矛盾：`update_weights` 先唤醒 vLLM（接收权重）再做 FSDP 全量 staging——但参数收集产出 CPU 张量，**根本不需要 vLLM 醒着**
4. 修复 = 逐单元导出（峰值 1.2MB）+ vLLM 休眠（-19.21GB）+ 跳过全量 staging → 实测 step 1 全程稳定

**7B 单卡内存预算（修复后）**：
- rollout 期：vLLM 20GB（util 0.45）+ FSDP 参数 CPU 旁置
- 训练期：vLLM 休眠（释放 19.21GB）→ actor 14.2GB + 激活 ≈ 28.7GB 峰值 ✓
- 权重同步期：逐单元 ≤1.2MB + vLLM 14.95GB ✓
