## 遇到的问题与解决方案

### 问题 1：成功率 0.7%——GRPO 信号几乎枯竭
**现象**：23 步（104 分钟）中，每 ~10 步才有 1 次有效学习信号（组内出现正样本）。

**关键判据（证明不是管道问题）**：
- 存在 2 条满分轨迹（证明判分/奖励/优势全链路正确）；
- 非零梯度（1.2~6.1）与非零优势（1.5）在有效步骤中均验证通过。

**根因**：**7B 模型在"Easy 档"题目上的能力天花板 ≈ 1%**——组内全错 = 优势恒 0。

**解决方案**：
1. 短期：接受信号稀疏，继续跑通管道（本阶段目标是工程验证，不是刷指标）；
2. 根本解：**升级模型**（后被 Run 07 的 30B-MoE 替代实现）。

## 沉淀
- **判断标准固化**：满分轨迹存在但稀疏 → 管道健康、能力不足 → 升模型；
  任何拓扑下 `score/max` 恒 0 → 查奖励链路（回 Run 01 诊断路径）。
- 小模型 RL 的瓶颈往往不是算法，而是**做题能力下限**。
